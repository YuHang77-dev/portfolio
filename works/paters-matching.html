マッチングアプリ「paters」新機能開発（PL）

累計会員数240万人超・累計マッチング数1,200万の「上質な出会い」マッチングアプリ。サービス成長フェーズの新機能企画・設計・実装をPLとしてリード。

  • React
  • TypeScript
  • PL / リード
  • API設計
  • 課金・サブスク

概要

累計会員数240万人超・累計マッチング数1,200万、24時間以内マッチング率97%を掲げるマッチングアプリ。iOS / Android / Web で展開するサービスの成長フェーズにおいて、新機能の企画・設計・実装をPL（10名体制）としてリードしました。

技術的課題

  • ユーザーエンゲージメント向上のための新機能開発
  • 「会いたい」「今日会いたい」等、リアルタイム性の高いマッチング体験の実現
  • 24時間365日の監視体制を維持しつつ、安全性と利便性を両立した機能設計
  • iOS / Android / Web 複数プラットフォームでの一貫したユーザー体験の担保

主な担当

  • PLとして開発チーム（6〜10名）のタスク管理・進捗管理・技術的意思決定をリード
  • 「会いたい」機能（リアルタイムマッチング）の設計・実装
  • メッセージ・トーク機能の拡張
  • 検索機能の高度化（属性・条件ベースフィルタリング）
  • 安全対策機能の強化（年齢確認・本人確認フロー、不正ユーザー検知）
  • 課金・サブスクリプション機能（有料プラン1/3/6/12ヶ月、ゴールドプラン）の実装

成果

  • 「会いたい」機能のリリースにより当日マッチング率の大幅向上とユーザーアクティブ率改善に貢献
  • PLとして開発チームをリードし、計画通りのスケジュールでリリースを達成
