01 — About

自己紹介

はじめまして、李翔太と申します。フルスタックエンジニアです。

日本企業との取引実績は9年以上。日本のビジネス文化や品質基準、開発現場でのコミュニケーションへの理解には自信があり、日本語での MTG・要件定義・ドキュメント作成にも対応しています。

これまで Web アプリケーション開発を中心に、フロントエンドからバックエンド、インフラ構築まで一通り経験してきました。要件定義から実装・運用まで一貫して関われるのが強みです。

「使いやすさ」と「保守しやすさ」の両立を大切にしながら、チームで協働してプロダクトを育てていくことに価値を感じています。技術選定では流行に流されず、課題解決に最適な手段を見極めることを意識しています。

PM・PL としてチームを率いた経験もあります。マッチングアプリの新機能開発（10名体制）や不動産サイトのリニューアル（8名体制）では PL として技術リードとタスク・品質管理を担当し、開発企業のコーポレートサイト新規構築（10名体制）では PM として要件定義からスケジュール・品質管理までを統括しました。一方で、技術選定から実装・インフラまで一人で完遂する小規模案件も多く手がけており、規模の異なる開発体制の双方で実績があります。

新しい技術を学ぶことが好きで、最近は AI 関連技術 — 特に LLM（大規模言語モデル）を活用したアプリケーション開発、RAG（検索拡張生成）や AI エージェントの実装に深く取り組んでいます。 日々の開発にも積極的に AI を取り入れ、開発効率の向上や新しいユーザー体験づくりに挑戦しています。

    YASIN社（台湾） / デザイナー → SE

    日本向け Web サイト・広告デザインの制作（Photoshop / Illustrator）からキャリアをスタートし、日本のデザイン慣習・商習慣を習得。 その後 Web システム＋アプリ開発の DB 設計・開発・結合テストと日本側との折衝・通訳を担当（Ruby on Rails / Django / Laravel / Java）。
